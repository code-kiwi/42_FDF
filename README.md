# FDF

This project was developed as part of the École 42 curriculum.

## Objective
The goal of this project is to render a 3D wireframe representation of a height map,
introducing the fundamentals of computer graphics and geometric transformations.

## Key concepts
- 2D to 3D projection
- Isometric and perspective projections
- Coordinate transformations
- Color interpolation based on height
- Event handling and basic user interaction

## Technical stack
- C
- MiniLibX
- Basic linear algebra
- Linux

## Notes
This project served as an introduction to computer graphics concepts and laid the
foundation for more advanced graphical projects such as Cub3D.
